# Documentation

Project documentation and visual assets live in this directory. See the main [README](../README.md) for quick-start instructions, environment setup, and CI/CD details.

## Visual Assets (`docs/img/`)

| File | Purpose |
| --- | --- |
| `logo.svg` | Vector brand mark used in the README header and Setup Wizard |
| `banner-dark.svg` / `banner-light.svg` | Adaptive hero showcase banners for dark and light themes |
| `architecture-dark.svg` / `architecture-light.svg` | Adaptive platform-to-application architecture diagrams |
| `wizard-preview.svg` | Setup Wizard preview shown during framework selection |

> [!NOTE]
> Once your framework is installed via the Setup Wizard, feel free to replace these template graphics and expand this directory with your application's own architecture notes, ADRs, or API documentation.
